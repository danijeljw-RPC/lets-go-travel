# Issue Records

Issue records capture questions and product choices that must not be answered implicitly during implementation. Each issue provides options, a recommendation, evidence needed and closure criteria.

Use `docs/issues/open/OI-####-short-kebab-title.md` for open or in-review issues. `in-review` means a direction is selected but required external evidence is not complete. Move a record to `docs/issues/closed/` only after its decision and supporting owner or external evidence are recorded. Update [Issue Index](index.md) whenever issue state changes.

Use the [Open Issue Template](templates/open-issue-template.md). Do not invent external tracker numbers.
