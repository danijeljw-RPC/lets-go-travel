# Open Issues

Open issues capture questions that must not be answered implicitly during implementation. Each issue provides options, a recommendation, evidence needed, and closure criteria.

Use `docs/issues/open/OI-####-short-kebab-title.md` for active issues and move resolved records to `docs/issues/closed/` only after the answer and evidence are recorded. Update [Issue Index](index.md) whenever issue state changes.

Use the [Open Issue Template](templates/open-issue-template.md). Do not invent external tracker numbers.
